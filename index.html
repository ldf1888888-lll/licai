本系统直接在当前浏览器保存资料，不连接私人云端。每次确认购买后，建议点击上方「本地导出备份」保存 JSON 文件。更换手机、浏览器或清理网站数据时，请用「恢复JSON备份」导入。

数据真实原则：必须获取天天基金历史净值，以及中国/海外市场指数的有效日期，缺一不可则停止生成买卖数额。不使用模拟行情，新闻不作为确定性交易信号；过去收益不代表未来。保存代表你本人确认已经执行，不会自动下单。
数据口径、成本风险及部署提示

净值算法沿用原有资金比例：货币基准15%、纳指20%，其余资金由中风险/中高风险按吸引力动态调整。120日净值位置不是估值PE/PB；QDII和A股实际市场存在净值时间差。

历史确认净值来自天天基金（东方财富）公开数据接口，可能变更或限制访问。刷新只换净值，不改代码。按行情优选才会触发更换候选代码，而且须先确认。

QDII真实限额因购买渠道、交易日期而变化，需用户核实。各金额未扣除申购费、赎回费、持有期限费用及税费。半年轮动是半年复核，不代表必须卖出；长期定投标注的代码不会因复核而变更。

本版不需要 Cloudflare Worker、D1、密钥或登录密码。投资记录只保存在当前浏览器本地，请定期下载 JSON 备份。GitHub Pages 代码及网页对任何知道网址的人公开，请勿将密码、账户证件或投资记录直接写进源码。
